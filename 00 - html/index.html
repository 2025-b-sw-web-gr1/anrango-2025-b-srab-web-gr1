1. 📄 Declaración DOCTYPE

La declaración <!DOCTYPE html> le dice al navegador que tipo de documento HTML estamos usando. Debe aparecer al inicio del documento, antes de cualquier etiqueta HTML.

Ejemplo básico de estructura HTML:

<!DOCTYPE html> <html> <body> <h1>Mi Primera Página Web</h1> <p>Este es mi primer párrafo.</p> </body> </html>
💡 Nota importante: El DOCTYPE para HTML5 es simplemente <!DOCTYPE html> - es case-insensitive y debe aparecer solo una vez al inicio del documento.

2. 🏗️ Estructura del Documento HTML

Todo documento HTML tiene una estructura básica que incluye:

  • <html>: El elemento raíz
  • <head>: Contiene metadatos del documento
  • <body>: Contiene el contenido visible

Estructura completa recomendada:

<!DOCTYPE html> <html lang="es"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>Título de la página</title> </head> <body> <h1>Contenido principal aquí</h1> <p>El contenido visible va dentro del body.</p> </body> </html>

3. 🏷️ Elementos HTML

Un elemento HTML está definido por una etiqueta de apertura, algún contenido, y una etiqueta de cierre.

Estructura de un elemento HTML:

<nombre-etiqueta>El contenido va aquí...</nombre-etiqueta>

Ejemplos de elementos HTML:

<h1>Mi Primer Encabezado</h1> <p>Mi primer párrafo.</p>
Etiqueta de Apertura Contenido del Elemento Etiqueta de Cierre
<h1> Mi Primer Encabezado </h1>
<p> Mi primer párrafo. </p>
<br> ninguno ninguno
📝 Nota: Algunos elementos HTML no tienen contenido (como el elemento <br>). Estos se llaman elementos vacíos y no tienen etiqueta de cierre.

🪆 Elementos HTML Anidados

Los elementos HTML pueden estar anidados (esto significa que los elementos pueden contener otros elementos). Todos los documentos HTML consisten en elementos HTML anidados.

Ejemplo de anidación:

<!DOCTYPE html> <html> <body> <h1>Mi Primer Encabezado</h1> <p>Mi primer párrafo.</p> </body> </html>

Explicación del anidamiento:

  • 🌟 El elemento <html> es el elemento raíz y define todo el documento HTML
  • 🏗️ Dentro del elemento <html> hay un elemento <body>
  • 📄 Dentro del elemento <body> hay dos elementos: <h1> y <p>
<html>
<body>
<h1>Mi Primer Encabezado</h1>
<p>Mi primer párrafo.</p>

🚫 Nunca Omitas la Etiqueta de Cierre

Algunos elementos HTML se mostrarán correctamente, incluso si olvidas la etiqueta de cierre, pero nunca confíes en esto. Pueden ocurrir resultados inesperados y errores.

❌ Ejemplo incorrecto (aunque funcione):

<html> <body> <p>Este es un párrafo <p>Este es otro párrafo </body> </html>

✅ Ejemplo correcto:

<html> <body> <p>Este es un párrafo</p> <p>Este es otro párrafo</p> </body> </html>

🔳 Elementos HTML Vacíos

Los elementos HTML sin contenido se llaman elementos vacíos. Estos elementos no tienen etiqueta de cierre.

Ejemplos de elementos vacíos:

<!-- Salto de línea --> <p>Este es un <br> párrafo con un salto de línea.</p> <!-- Línea horizontal --> <p>Párrafo 1</p> <hr> <p>Párrafo 2</p> <!-- Imagen --> <img src="imagen.jpg" alt="Una imagen"> <!-- Campo de entrada --> <input type="text" placeholder="Escribe aquí">

🔤 HTML No Distingue Mayúsculas y Minúsculas

Las etiquetas HTML no distinguen entre mayúsculas y minúsculas: <P> significa lo mismo que <p>.

Todas estas son válidas:

<P>Párrafo en mayúsculas</P> <p>Párrafo en minúsculas</p> <P>Párrafo mixto</p>
✅ Recomendación: Aunque HTML acepta mayúsculas, el estándar W3C recomienda usar minúsculas en HTML y lo exige para documentos más estrictos como XHTML.

4. 📋 Encabezados HTML (H1-H6)

Los encabezados se definen con las etiquetas <h1> hasta <h6>. <h1> es el más importante y <h6> el menos importante.

Ejemplos de encabezados:

<h1>Este es un encabezado H1</h1> <h2>Este es un encabezado H2</h2> <h3>Este es un encabezado H3</h3> <h4>Este es un encabezado H4</h4> <h5>Este es un encabezado H5</h5> <h6>Este es un encabezado H6</h6>

🎯 Buena práctica: Usa H1 para el título principal, H2 para secciones importantes, y así sucesivamente. Mantén una jerarquía lógica.

📋 Guía de Uso por Encabezado

Encabezado Cuándo usar Ejemplos
<h1> Título principal de la página.
Solo uno por página		 Nombre del sitio, título del artículo principal, nombre de la empresa
<h2> Secciones principales del contenido Capítulos, secciones del menú, categorías principales
<h3> Subsecciones dentro de H2 Temas específicos, subcategorías
<h4> Divisiones menores dentro de H3 Listas de elementos, características específicas
<h5> Detalles o elementos muy específicos Tipos, variantes, opciones
<h6> Notas menores, metadatos, comentarios Fechas de actualización, notas del autor, versiones
🚨 Errores comunes a evitar:
  • ❌ Usar múltiples H1 en la misma página
  • ❌ Saltar niveles (H2 → H4 sin H3)
  • ❌ Usar encabezados solo por el tamaño visual
  • ❌ No seguir una jerarquía lógica
✅ Buenas prácticas:
  • ✅ Un solo H1 por página
  • ✅ Mantener orden jerárquico (H1→H2→H3→H4...)
  • ✅ Usar encabezados para estructura, no solo diseño
  • ✅ Hacer encabezados descriptivos y claros

5. 📝 Párrafos HTML

Los párrafos se definen con la etiqueta <p>. Cada párrafo se muestra en una nueva línea con espacio automático antes y después.

Ejemplo de párrafos:

<p>Este es un párrafo de ejemplo.</p> <p>Este es otro párrafo. Los párrafos se separan automáticamente.</p> <p>Puedes escribir texto más largo en un párrafo y se ajustará automáticamente al ancho disponible de la ventana del navegador.</p>

6. 🔗 Enlaces HTML

Los enlaces se crean con la etiqueta <a> y el atributo href especifica el destino del enlace.

Tipos de enlaces:

<!-- Enlace a otra página web --> <a href="https://www.google.com">Ir a Google</a> <!-- Enlace a otra página local --> <a href="otra-pagina.html">Ir a otra página</a> <!-- Enlace a una sección de la misma página --> <a href="#seccion1">Ir a la sección 1</a> <!-- Enlace que abre en nueva ventana --> <a href="https://www.ejemplo.com" target="_blank">Abrir en nueva ventana</a> <!-- Enlace de email --> <a href="mailto:alguien@ejemplo.com">Enviar email</a>

7. 🖼️ Imágenes HTML

Las imágenes se insertan con la etiqueta <img>. Los atributos principales son src (fuente), alt (texto alternativo), width y height.

Ejemplos de imágenes:

<!-- Imagen básica --> <img src="mi-imagen.jpg" alt="Descripción de la imagen"> <!-- Imagen con dimensiones específicas --> <img src="logo.png" alt="Logo de la empresa" width="200" height="100"> <!-- Imagen responsiva --> <img src="foto.jpg" alt="Una hermosa foto" style="width:100%; max-width:400px;"> <!-- Imagen desde internet --> <img src="https://via.placeholder.com/300x200" alt="Imagen de ejemplo">

🔍 Accesibilidad: Siempre incluye el atributo alt para describir la imagen. Es esencial para lectores de pantalla y SEO.

8. ⚙️ Atributos HTML

Los atributos proporcionan información adicional sobre los elementos HTML. Se escriben dentro de la etiqueta de apertura.

Atributos comunes:

<!-- Atributo id (identificador único) --> <h1 id="titulo-principal">Título Principal</h1> <!-- Atributo class (para estilos CSS) --> <p class="texto-destacado">Párrafo con clase</p> <!-- Atributo style (estilos en línea) --> <p style="color: blue; font-size: 18px;">Texto azul y grande</p> <!-- Atributo title (tooltip) --> <p title="Información adicional">Pasa el mouse sobre este texto</p> <!-- Múltiples atributos --> <a href="https://ejemplo.com" target="_blank" title="Enlace externo" class="enlace-azul"> Enlace con múltiples atributos </a>

9. 🛠️ Herramientas para Ver y Editar HTML

Aprende a inspeccionar y debuggear tu código HTML usando las herramientas del navegador.

Cómo ver el código fuente HTML:

  • Ver código fuente completo:
    • Windows/Linux: Ctrl + U
    • Mac: Cmd + Option + U
    • Click derecho → "Ver código fuente de la página"
  • Inspeccionar elemento específico:
    • Click derecho en cualquier elemento → "Inspeccionar"
    • Windows/Linux: F12
    • Mac: Cmd + Option + I

¿Qué puedes hacer con las herramientas de desarrollo?

  • ✅ Ver y editar HTML en tiempo real
  • ✅ Modificar estilos CSS temporalmente
  • ✅ Debuggear JavaScript
  • ✅ Analizar el rendimiento de la página
  • ✅ Simular diferentes dispositivos móviles
