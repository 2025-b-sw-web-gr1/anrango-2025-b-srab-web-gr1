# Catálogo Tecnológico 2085 - Taller Clase 07

Proyecto web desarrollado con **Handlebars** como motor de renderizado para el curso de Aplicaciones Web.

## 🚀 Instalación

```bash
npm install
```

## ▶️ Ejecución

### Modo desarrollo (con auto-reinicio)
```bash
npm run dev
```

### Modo producción
```bash
npm start
```

Abrir navegador en: **http://localhost:3000**

## 📁 Estructura del Proyecto

```
07-Clase/
├── server.js                 # Servidor Express
├── package.json              # Dependencias
├── views/                    # Plantillas Handlebars
│   ├── layouts/
│   │   └── main.handlebars
│   ├── partials/
│   │   └── invento-card.handlebars
│   └── index.handlebars
├── public/
│   ├── css/
│   │   └── styles.css
│   └── js/
│       └── main.js
└── explicacion.md            # Documentación completa
```

## 🛠️ Tecnologías Utilizadas

- **Node.js** + **Express** - Framework web
- **Handlebars** - Motor de plantillas
- **CSS3** - Estilos futuristas
- **JavaScript** - Interactividad
