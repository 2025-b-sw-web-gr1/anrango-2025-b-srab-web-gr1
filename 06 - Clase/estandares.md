## 1. HTML5

### Descripción
HTML5 es la quinta versión del lenguaje de marcado que estructura el contenido web. Introduce elementos semánticos (`<header>`, `<nav>`, `<article>`, `<section>`, `<footer>`), APIs para multimedia nativa (`<video>`, `<audio>`), almacenamiento local y capacidades de dibujo en canvas.

### Importancia en la web moderna
HTML5 eliminó la dependencia de plugins externos como Flash para reproducir multimedia, estandarizó la estructura semántica de documentos web y permitió el desarrollo de aplicaciones web robustas. Es la base sobre la cual se construye prácticamente cualquier sitio web actual.

### Beneficio para desarrolladores
Permite escribir código más limpio y accesible mediante elementos semánticos que tanto navegadores como motores de búsqueda comprenden mejor. Reduce la complejidad técnica al integrar multimedia de forma nativa y facilita el mantenimiento del código a largo plazo.

## 2. CSS3

### Descripción
CSS3 (Cascading Style Sheets Level 3) es el estándar actual para definir la presentación visual de documentos HTML. Introduce módulos como Flexbox, Grid, animaciones, transformaciones, transiciones, variables CSS (custom properties) y media queries para diseño responsivo.

### Importancia en la web moderna
CSS3 permite crear interfaces visuales complejas sin necesidad de JavaScript o imágenes pesadas. El diseño responsivo a través de media queries es fundamental para adaptar sitios a cualquier dispositivo, desde móviles hasta pantallas 4K.

### Beneficio para desarrolladores
Reduce el tiempo de desarrollo al ofrecer herramientas poderosas como Grid y Flexbox para layouts complejos. Las animaciones CSS son más eficientes que las basadas en JavaScript, mejorando el rendimiento. Variables CSS facilitan la creación de sistemas de diseño escalables y mantenibles.

## 3. WAI-ARIA (Accessible Rich Internet Applications)

### Descripción
WAI-ARIA es un conjunto de atributos que mejoran la accesibilidad de aplicaciones web dinámicas. Define roles (`role`), estados (`aria-expanded`, `aria-disabled`) y propiedades (`aria-label`, `aria-describedby`) que describen la funcionalidad de elementos interactivos para tecnologías asistivas como lectores de pantalla.

### Importancia en la web moderna
La web debe ser accesible para todos, incluyendo personas con discapacidades visuales, auditivas o motoras. ARIA cierra la brecha entre aplicaciones web complejas (modales, tabs, acordeones) y la capacidad de los lectores de pantalla para interpretarlas correctamente.

### Beneficio para desarrolladores
Cumplir con estándares de accesibilidad no solo es éticamente correcto, sino legalmente requerido en muchas jurisdicciones. ARIA permite crear componentes interactivos complejos que siguen siendo usables para todos. Mejora el SEO y amplía la audiencia potencial de cualquier producto web.

## 4. SVG (Scalable Vector Graphics)

### Descripción
SVG es un formato de imagen vectorial basado en XML que permite crear gráficos escalables sin pérdida de calidad. Soporta interactividad, animaciones, filtros y puede ser manipulado mediante CSS y JavaScript.

### Importancia en la web moderna
En un mundo multi-dispositivo con diferentes densidades de píxeles (pantallas Retina, 4K), SVG garantiza que íconos, logos e ilustraciones se vean nítidos en cualquier resolución. El tamaño de archivo es significativamente menor que imágenes rasterizadas equivalentes.

### Beneficio para desarrolladores
Un solo archivo SVG sirve para todas las resoluciones, eliminando la necesidad de crear múltiples versiones de la misma imagen. Es editable con código, lo que permite cambios dinámicos de color, tamaño o forma mediante CSS/JS. Reduce el peso total de las páginas web, mejorando tiempos de carga.

## 5. Web Content Accessibility Guidelines (WCAG) 2.1

### Descripción
WCAG 2.1 establece criterios específicos para hacer contenido web accesible. Se organiza en cuatro principios: Perceptible, Operable, Comprensible y Robusto. Define tres niveles de conformidad (A, AA, AAA) con requisitos concretos sobre contraste de color, navegación por teclado, texto alternativo, etc.

### Importancia en la web moderna
WCAG es la referencia legal global para accesibilidad web. Organismos públicos, universidades y empresas deben cumplir al menos el nivel AA en muchos países. Un sitio inaccesible excluye potencialmente al 15% de la población mundial.

### Beneficio para desarrolladores
Seguir WCAG desde el inicio del proyecto evita costosas refactorizaciones posteriores. Las pautas mejoran la experiencia para todos los usuarios, no solo aquellos con discapacidades (por ejemplo, buen contraste ayuda en pantallas bajo sol directo). Demuestra profesionalismo y amplía oportunidades laborales en proyectos gubernamentales o corporativos grandes.
