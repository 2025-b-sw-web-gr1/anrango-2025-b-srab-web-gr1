1. CSS Externo (Archivo Separado)

¿Qué es?

El CSS externo se almacena en un archivo separado con extensión .css y se enlaza usando la etiqueta <link>.

Sintaxis:

<link rel="stylesheet" href="ruta/archivo.css">

Ventajas:

  • ✅ Reutilizable en múltiples páginas
  • ✅ Mantiene el HTML limpio y semántico
  • ✅ Cacheable por el navegador
  • ✅ Fácil mantenimiento
  • ✅ Permite trabajo en equipo

Desventajas:

  • ❌ Requiere petición HTTP adicional
  • ❌ Puede causar flash de contenido sin estilo (FOUC)

2. CSS Interno (Etiqueta <style>)

¿Qué es?

El CSS interno se define dentro de la etiqueta <style> en el <head> del documento HTML.

Sintaxis:

<style>
    .mi-clase {
        color: blue;
        font-size: 16px;
    }
</style>

Ventajas:

  • ✅ No requiere archivos externos
  • ✅ No hay peticiones HTTP adicionales
  • ✅ Útil para estilos específicos de una página

Desventajas:

  • ❌ No reutilizable
  • ❌ Aumenta el tamaño del HTML
  • ❌ Dificulta el mantenimiento

3. CSS Inline (Propiedad style)

¿Qué es?

El CSS inline se aplica directamente al elemento HTML usando el atributo style.

Sintaxis:

<div style="color: red; font-weight: bold;">Texto</div>

Ventajas:

  • ✅ Máxima especificidad
  • ✅ Aplicación inmediata
  • ✅ Útil para estilos únicos

Desventajas:

  • ❌ Mezcla contenido con presentación
  • ❌ Difícil de mantener
  • ❌ No reutilizable
  • ❌ Aumenta el tamaño del HTML

4. CSS con @import

¿Qué es?

La regla @import permite importar hojas de estilo desde CSS o HTML.

Sintaxis:

<style>
    @import url("archivo.css");
    @import "https://fonts.googleapis.com/css2?family=Roboto";
</style>

Ventajas:

  • ✅ Permite importación condicional
  • ✅ Útil para organizar CSS modular
  • ✅ Puede importar desde URLs

Desventajas:

  • ❌ Bloquea la renderización
  • ❌ Múltiples peticiones HTTP secuenciales
  • ❌ Peor rendimiento que <link>

5. Carga Dinámica con JavaScript

¿Qué es?

Permite cargar CSS de forma dinámica usando JavaScript, útil para carga condicional o lazy loading.

Sintaxis:

// Crear elemento link
const link = document.createElement('link');
link.rel = 'stylesheet';
link.href = 'archivo.css';
document.head.appendChild(link);

// O modificar estilos directamente
document.body.style.backgroundColor = 'blue';

Ventajas:

  • ✅ Carga bajo demanda
  • ✅ Control programático
  • ✅ Optimización de rendimiento
  • ✅ Estilos condicionales

Desventajas:

  • ❌ Requiere JavaScript habilitado
  • ❌ Complejidad adicional
  • ❌ Posible flash de contenido sin estilo

Tabla Comparativa

Método Reutilizable Rendimiento Mantenimiento Uso Recomendado

🏆 Mejores Prácticas

1. Usa CSS Externo

Para la mayoría de estilos. Mantiene el código organizado y permite reutilización.

2. CSS Interno para específicos

Solo para estilos únicos de una página que no se repetirán.

3. Inline con moderación

Úsalo solo para estilos dinámicos o sobrescribir temporalmente.

4. @import para fuentes

Ideal para Google Fonts u otras librerías de terceros.
