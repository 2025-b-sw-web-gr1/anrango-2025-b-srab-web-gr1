# 🐱 SPA Gatito - Single Page Application

Una aplicación de una sola página (SPA) construida con **Vite** y **Vanilla JavaScript** que demuestra el concepto de navegación sin recargas de página.

## 🚀 Características

- ✅ **SPA Real**: Navegación sin recargas de página
- ✅ **Sistema de Rutas**: Manejo de rutas con hash (#)
- ✅ **Vanilla JavaScript**: Sin frameworks, JavaScript puro
- ✅ **Diseño Moderno**: CSS3 con gradientes y animaciones
- ✅ **Responsive**: Adaptable a diferentes tamaños de pantalla
- ✅ **Vite**: Build tool ultrarrápido para desarrollo

## 📁 Estructura del Proyecto

```
spa-gatito-template/
├── index.html              # HTML principal con navegación
├── src/
│   ├── main.js             # Lógica principal del SPA
│   ├── style.css           # Estilos CSS modernos
│   └── assets/
│       └── gatito.jpg      # Imagen SVG del gatito
├── package.json            # Configuración de Vite
└── README.md              # Este archivo
```

## 🛠️ Tecnologías Utilizadas

- **Vite** - Build tool y servidor de desarrollo
- **Vanilla JavaScript** - Lógica de la aplicación
- **CSS3** - Estilos modernos con gradientes y animaciones
- **HTML5** - Estructura semántica

## 🌐 Rutas Disponibles

- `/` - Página de inicio con información sobre SPAs
- `/gatito` - Página del gatito con datos curiosos

## 🎯 Conceptos Demostrados

### 1. Single Page Application (SPA)
- Navegación sin recargas de página
- Actualizaciones dinámicas del contenido
- Gestión del historial del navegador

### 2. Sistema de Rutas Simple
- Uso de hash (#) para las rutas
- Event listeners para cambios de ruta
- Renderizado condicional de componentes

### 3. Programación Orientada a Objetos
- Clase principal `SpaGatito`
- Métodos organizados y reutilizables
- Encapsulación de la lógica

### 4. Modern CSS
- Variables CSS personalizadas
- Gradientes y efectos visuales
- Animaciones y transiciones suaves
- Diseño responsive

## 🚀 Cómo Usar

El proyecto ya está corriendo con Vite. Simplemente navega entre las rutas:

- **Página de Inicio**: http://localhost:5173/#/
- **Página del Gatito**: http://localhost:5173/#/gatito

## 🎨 Características del Diseño

- **Navegación Fija**: Barra de navegación que permanece visible
- **Efectos Glass**: Fondo translúcido con blur effect
- **Transiciones Suaves**: Animaciones de entrada para el contenido
- **Hover Effects**: Efectos interactivos en botones e imágenes
- **Gradientes Modernos**: Colores atractivos y modernos

## 📱 Responsive Design

El diseño se adapta automáticamente a:
